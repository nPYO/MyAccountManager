# 使い方・更新・データの保管

## 起動と保存場所

配布ZIPを展開し、MyAccountManager.exeを起動します。アプリはEXEの隣にMyAccountManager.datフォルダーを作成して利用者データを保存します。配布ZIPに登録済みデータはありません。

Windowsの保護されたフォルダーへ置かず、書込みできる場所で使用してください。StandardとPortableは別の配布版です。別の場所へ展開しただけで既存データを自動的に引き継ぐものではありません。

## 基本操作

初回登録後、「アカウントを追加」から情報を登録します。詳細を表示してコピー・編集し、離席時は「ロック」を使用します。
「項目を整理」では項目の追加・削除・並べ替えができます。実際に移動した項目は枠で示され、他の要素をクリックするか画面を移動すると解除されます。

二段階認証欄ではQR画像を選択・貼付けしてTOTPを登録できます。QR画像と設定用QRは秘密情報として扱ってください。

## バックアップと復元

「設定・管理」から手動バックアップを作成します。復元に必要なユーザー名・パスワードを忘れないでください。
復元キーを発行した場合は、対応するバックアップとともに安全な場所へ保管します。復元キーだけではアカウントデータを復元できません。
認証情報・対応する復元手段を失ったデータを、作者が復号することはできません。

復元すると現在の保管庫が置き換わる操作があります。画面の対象・影響を確認し、実行前に現在のデータをバックアップしてください。

## 更新

1. 起動中のアプリを終了する前に、アプリから手動バックアップを作成します。
2. アプリを終了します。
3. 同じ配布版の新しいZIPを別フォルダーへ展開し、チェックサムを照合します。
4. 既存のEXEを新しいEXEへ置き換えます。MyAccountManager.datを削除・上書きしないでください。
5. 起動して既存のデータを確認します。

DB保存先を変更している場合は、その指定フォルダーも保管対象です。アプリ起動中にDBや関連ファイルを移動しないでください。
StandardとPortableを切り替える場合や別PCへ移行する場合は、アプリのバックアップ・復元機能を使用してください。

## HTML出力

HTML出力は暗号化バックアップではありません。機密情報を含める出力は平文になります。共有先・保存先に注意し、不要になった出力を適切に管理してください。
